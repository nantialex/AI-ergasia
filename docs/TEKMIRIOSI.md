## 1. Κόσμος, αρχική/τελική κατάσταση, χώρος καταστάσεων

### 1.i Κόσμος του προβλήματος

Η αποθήκη αποτελείται από:

- **Είσοδο** (θέση 0)
- **Πέντε διαδοχικές θέσεις** αποθήκευσης (1–5)

Το ρομπότ κινείται κατά μία θέση αριστερά/δεξιά, φορτώνει δέματα από την ουρά της τρέχουσας θέσης και τα παραδίδει στην είσοδο.

Περιορισμοί χώρου μεταφοράς (cargo):

- το πολύ **3** δέματα
- συνολικό βάρος το πολύ **20 kg**

### 1.ii Αρχική και τελική κατάσταση

**Αναπαράσταση κατάστασης** (κλάση `State`):

```text
State = (robot_pos, cargo, shelves, entrance)
```

- `robot_pos ∈ {0,1,2,3,4,5}`
- `cargo`: πλειάδα βαρών που μεταφέρει το ρομπότ
- `shelves`: 5 ουρές δεμάτων (το πρώτο στοιχείο εξετάζεται πρώτο)
- `entrance`: δέματα που έχουν ήδη εκφορτωθεί

**Αρχική κατάσταση (εκφώνηση):**

| Θέση | Δέματα (kg)   |
|------|---------------|
| 1    | 12, 15        |
| 2    | 8, 11         |
| 3    | 3, 9, 7       |
| 4    | 6, 2, 13      |
| 5    | 10, 4         |
| Είσοδος | (κενή)     |
| Ρομπότ  | στην είσοδο, cargo κενό |

**Τελική κατάσταση:** όλα τα δέματα στην είσοδο, δηλαδή ράφια κενά και `cargo = ()`.  
Ελέγχεται από τη συνάρτηση `is_goal_state`.

### 1.iii Χώρος καταστάσεων

Ο χώρος καταστάσεων είναι το σύνολο όλων των έγκυρων `State` που προκύπτουν από διαδοχική εφαρμογή τελεστών, ξεκινώντας από την αρχική.

Περιγραφικά:

- Κάθε κατάσταση χαρακτηρίζεται από θέση ρομπότ, περιεχόμενο cargo, κατανομή δεμάτων στα 5 ράφια και στην είσοδο.
- Οι μεταβάσεις προκύπτουν μόνο από εφαρμόσιμους τελεστές (`find_children`).
- Καταστάσεις με ίδιο κανονικό κλειδί (`canonical_key`) θεωρούνται ίδιες για το κλειστό σύνολο (αποφυγή κύκλων).

Αντιπροσωπευτικά παραδείγματα (λίστα):

1. Αρχή: `pos=0, cargo=(), shelves=((12,15),(8,11),…), entrance=()`
2. Μετά από `move_right`: `pos=1, cargo=()`
3. Μετά από `load`: `pos=1, cargo=(12,), shelves=((15),…)`
4. Όταν `12+15>20`: εφαρμόζεται `return_and_unload` → `pos=0, cargo=(), entrance=(12,)`
5. Στόχος: `shelves=(((),)*5), cargo=(), entrance=(…όλα τα δέματα…)`

---

## 2. Τελεστές μετάβασης και `find_children`

| Τελεστής            | Συνθήκη εφαρμογής                                      | Αποτέλεσμα                          |
|---------------------|--------------------------------------------------------|-------------------------------------|
| `move_left`         | `robot_pos > 0`                                        | θέση −1                             |
| `move_right`        | `robot_pos < 5`                                        | θέση +1                             |
| `load`              | σε θέση 1–5, υπάρχει δέμα που χωράει στο cargo         | φόρτωση ενός δέματος                |
| `return_and_unload` | σε θέση 1–5, μη κενό cargo, το επόμενο δέμα δεν χωράει | είσοδος + εκφόρτωση σε **μία** ενέργεια |
| `unload`            | στην είσοδο με μη κενό cargo                           | εκφόρτωση όλων στο `entrance`       |

Η `find_children(state)` εφαρμόζει όλους τους τελεστές και επιστρέφει τα ζεύγη `(όνομα, νέα_κατάσταση)`.

Υλοποίηση: `warehouse_robot/operators.py` (σχολιασμένος κώδικας).

## 3. DFS και BFS με παρακολούθηση μετώπου

- **DFS:** στοίβα (LIFO), κλειστό σύνολο με `canonical_key`.
- **BFS:** ουρά (FIFO), κλειστό σύνολο· εγγυάται λύση ελάχιστου μήκους (πλήθος ενεργειών).
- **Παρακολούθηση μετώπου:** σημαία `--monitor` εκτυπώνει σε κάθε βήμα την ουρά/στοίβα μονοπατιών.

```bash
python main.py --method dfs --scenario small --monitor
python main.py --method bfs --scenario small --monitor
```

## 4. Δένδρο αναζήτησης (πρώτα 4 επίπεδα)

Μη εξαντλητικό δένδρο από την αρχική κατάσταση:

```bash
python main.py --tree --scenario small --tree-depth 4
python main.py --tree --scenario assignment --tree-depth 4
```

Σε κάθε κόμβο εμφανίζονται: τελεστής, θέση ρομπότ, cargo, υπόλοιπα δέματα στα ράφια, πλήθος στην είσοδο.

---

## 5. Ευριστική μέθοδος

Υλοποιήθηκε **Best-First Search** με προτεραιότητα `h(n)`:

\[
h(n) = \text{δέματα\_στα\_ράφια} + [\text{cargo}\neq\emptyset] + 0.1\cdot\text{απόσταση} + \lceil\text{δέματα}/3\rceil
\]

- Ενθαρρύνει καταστάσεις με λιγότερα εκκρεμή δέματα.
- Όταν υπάρχει cargo, προτιμά επιστροφή προς την είσοδο.
- Υλοποίηση: `warehouse_robot/heuristics.py`, αναζήτηση: `best_first_search`.

```bash
python main.py --method heuristic --scenario assignment
```

---

## 6. Επιλογή μεθόδου και `is_goal_state`

Η επιλογή γίνεται από τη γραμμή εντολών (`--method dfs|bfs|heuristic`).

Η `is_goal_state(state)` επιστρέφει `True` όταν δεν απομένουν δέματα στα ράφια και το cargo είναι κενό.

## 7. Περιπτώσεις ελέγχου και συγκριτική μελέτη

### Σενάρια

| Σενάριο      | Περιγραφή                                      |
|--------------|------------------------------------------------|
| `small`      | 3 δέματα σε 2 θέσεις — γρήγορος έλεγχος        |
| `medium`     | 7 δέματα σε 4 θέσεις                           |
| `tight`      | βαριά δέματα → συχνό `return_and_unload`       |
| `assignment` | πλήρες πρόβλημα εκφώνησης (12 δέματα)          |

### Εκτέλεση συγκριτικής μελέτης

```bash
python main.py --compare
python -m unittest discover -s tests -v
```

### Ενδεικτικά αποτελέσματα (`python3 main.py --compare`)

| Σενάριο    | Μέθοδος     | Επιτυχία | Μήκος λύσης | Επεκτάσεις | Μέγ. μέτωπο |
|------------|-------------|----------|-------------|------------|-------------|
| assignment | DFS         | ΝΑΙ      | 98          | 122        | 68          |
| assignment | BFS         | ΝΑΙ      | **39**      | 30685      | 2181        |
| assignment | Best-First  | ΝΑΙ      | 54          | **67**     | 31          |
| small      | DFS / BFS / Best-First | ΝΑΙ | 14 / **8** / 11 | — | — |
| medium     | DFS / BFS / Best-First | ΝΑΙ | 46 / **21** / 31 | — | — |
| tight      | DFS / BFS / Best-First | ΝΑΙ | 36 / **20** / 23 | — | — |

### Συμπεράσματα

1. **BFS** βρίσκει τη συντομότερη λύση σε πλήθος ενεργειών· απαιτεί πολύ μεγαλύτερο μέτωπο και περισσότερες επεκτάσεις.
2. **DFS** κρατά μικρό μέτωπο και λίγες επεκτάσεις στο συγκεκριμένο ordering τελεστών, αλλά επιστρέφει μακρύτερο μονοπάτι.
3. **Best-First** επεκτείνει τους λιγότερους κόμβους στα μεγάλα στιγμιότυπα χάρη στην `h(n)`, με μήκος λύσης μεταξύ DFS και BFS.
4. Και οι τρεις μέθοδοι επιλύουν το πλήρες πρόβλημα της εκφώνησης· η επιλογή εξαρτάται από το αν προτεραιότητα έχει το βέλτιστο μήκος (BFS) ή η ταχύτητα/μνήμη (DFS / Best-First).
